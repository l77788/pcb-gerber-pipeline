PCB_lightgraph 同类开源项目对比

围绕「把 2D 图片 / 插画转成可打样的 PCB」这一用途，在 GitHub 上检索到的可参考项目
PCB_lightgraph 是一键把 2D 插画转成可制造 PCB 分层图纸的桌面工具，自动拆分为铜层 / 阻焊 / 丝印 / 背透光四层，支持单面 5 色 + 透光。以下按「工作方式」分区对比同类项目。

最直接同类：图片 → PCB 分层 / Gerber

与 PCB_lightgraph 定位最接近的一类
项目技术栈 / 形态输入 → 输出亮点与 lightgraph 差异
pcb-art Python，项目整合 任意图片 → PCB 各层光绘文件 可直接导入 立创 EDA 编辑或下单，输出银行卡尺寸（54×85.6 mm）带圆角卡片 面向「做一张 PCB 艺术卡片」；单层逻辑由代码管理，无桌面 GUI
eext-image-contour-to-pcb 嘉立创官方扩展 图片 → 轮廓 → 艺术 PCB 嘉立创 EDA 专业版官方插件，一张图即可构建艺术 PCB 是 EDA 内辅助扩展，不独立拆色/分层，依赖嘉立创生态
PCB_art_Blue 开源软件流程 位图 → 铜层 / 阻焊 / 丝印 主图点击吸色做色彩聚类，分色合并降噪，再加标记点成物理层 流程更偏 DIY 开源教程，处理艺术画而非「灯光分层」
gerbolyze Python + Rust (svg-flatten) SVG / PNG / JPG → Gerber / Excellon 矢量无损渲染、支持完整 SVG 1.1，命令行可直接产出制造文件 是「转换器」而非完整工具，不做拆层/灯光；本项目管线正使用它
bmp2pcb 命令行工具（经典） 单色 BMP → KiCad/Eagle 或 Gerber 把 Logo / 图案蚀刻到 PCB 铜层的经典老工具 只支持单色位图，无彩色拆分

KiCad 体系内的图片 → 艺术 / 丝印

把图转进 KiCad 封装或丝印/铜层
项目形态输入 → 输出亮点与 lightgraph 差异
svg2shenzhen Inkscape 扩展 SVG → KiCad PCB / footprint 任意形状、钻孔盘、板框；跨平台（OSX/Win/Linux） 面向矢量图与 KiCad 手工流，不自动拆彩色插画
kicad_art_generator CLI（包装 svg2mod） SVG / PNG / JPG → KiCad 封装 用简单 CLI 把艺术图直接变 KiCad footprint，Linux-first 偏「封装生成」，不带灯光分层
kicad-img2silk (Img2Silk) KiCad 内转换 图片 → 丝印 / 铜 / 阻焊 5 种抖动算法（Atkinson / Bayer / Floyd–Steinberg…）+ 板子调色板多色模式 专注丝印与抖动艺术，不产完整分层工程
Gingerbread Web 工具 SVG → KiCad footprint Winterbloom 出品，专为 PCB 首饰/艺术设计 高度定制 Winterbloom 用途，非通用拆层
参考向：PCB_Business_Card（KiCad 做 PCB 名片的 Gerber 示例）、openjlc / TransJLC（Rust 写的 AD/KiCad → JLC 快速 Gerber 转换，属于「格式转接」而非「图片艺术」，但与本项目「为嘉立创下单准备」的目标相关）。

结论

在 GitHub 上没有找到与 PCB_lightgraph「桌面 GUI + 四层自动拆分 + 背透光灯光」完全同构的替代品。最接近的是 pcb-art（同样面向立创下单、图片→分层）与 gerbolyze（本文档所在管线实际使用的转换引擎）。 若你主要用 KiCad 手工做艺术板，svg2shenzhen 和 Img2Silk 值得参考；若是嘉立创生态，官方 eext-image-contour-to-pcb 可直接入手。

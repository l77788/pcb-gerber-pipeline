PCB_lightgraph → Gerber → 嘉立创

PCB 图片转 Gerber 打样方案

把 PCB_lightgraph 导出的四层 PNG（丝印 / 阻焊 / 铜层 / 背光）一键转成标准 RS-274X Gerber 并打包，上传嘉立创打样的完整方案、脚本与验证记录。

📖 开始使用（操作手册） ✅ 自检说明 🔍 同类项目调研 GitHub 仓库

快速上手

# 1. 一键向导（推荐）：自动检查环境、选文件夹、四层转换 + 打包
powershell -ExecutionPolicy Bypass -File run.ps1

# 2. 或直接参数化调用
powershell -ExecutionPolicy Bypass -File run.ps1 `
  -InputDir .\你的导出目录 -Name myboard -Size 80x60 -LineWidth 0.1

# 3. 生成的 out_myboard\myboard_gerber.zip 上传嘉立创，先在线逐层核对再下单
